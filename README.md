# Tyre Shop Management Website

A modern full-stack tyre retail management web application built for a physical tyre business. The platform allows customers to browse tyre listings while providing admins with secure inventory management capabilities.

## Live Demo

https://subharthiii.github.io/tyreShop/index.html

## Features

### Customer Features

* Browse tyre listings
* View tyre details and stock status
* Responsive UI for mobile and desktop
* Google Maps location integration
* WhatsApp and phone contact integration
* Dark mode / Light mode support

### Admin Features

* Secure Firebase Authentication
* Admin dashboard
* Add/Edit/Delete tyre listings
* Update stock availability
* Dynamic inventory management

## Tech Stack

* HTML
* CSS
* JavaScript
* Firebase Authentication
* Firestore Database
* GitHub Pages Deployment
